# GodotSynth: agent instructions

Canonical instructions for every coding agent. `CLAUDE.md` imports this file with `@AGENTS.md`.

## What this is

A GDExtension (C++, godot-cpp) that adds a modular synthesizer to Godot 4.7+, built against the 4.7 API. It provides an engine for virtual analog, chord and future synths, modulation sources, modulated effects, and a GDScript editor addon. It's a public MIT project (github.com/EclipsingLines/GodotSynth), in beta at v0.96. README.md documents the user-facing API and CHANGELOG.md the releases.

Work in progress: an audio-clock transport and a Strudel-style pattern ("cue") language for adaptive game music.

## Verify

```bash
bash tests/verify.sh
```

This builds the debug DLL with SCons, imports the project headlessly, and runs `tests/offline_render.gd`, `tests/smoke.gd` and every `tests/test_*.gd`. It exits 0 only when everything passes, and takes about 30 s incrementally.
- `bash tests/verify.sh --no-build tests/test_x.gd` reruns one script without rebuilding, which is enough for GDScript-only changes.
- **Test scripts:** a new test is `tests/test_<area>.gd`. It `extends SceneTree`, does its work in `_initialize()`, prints one `PASS <name>` or `FAIL <name>: <detail>` line per check, then calls `quit(0)` or `quit(1)`. Copy the structure of `tests/offline_render.gd`. Never let a script error loop: on an unexpected state, print `FAIL` and quit.
- Every audio bug fix gets a check in a test script.

## Build

- `tests/verify.sh` already strips Git Bash's MSYS entries from PATH and unsets `MSYSTEM`/`SHELL`. Otherwise SCons's MSVC detection fails under Git Bash. To build by hand from **PowerShell or cmd**: `python -m SCons target=template_debug -j8`. SCons is pinned to **4.11.1** (CI's `.github/actions/base-deps`, here, and the README's "Building from source"): change all three together.
- SConstruct collects every `.cpp` under `src/synth/` recursively, so new files need no build-script edits. It aborts if it finds no sources, and CI fails any library under 200 KB or without `synth_library_init`.
- Output goes to `godot_synth/bin/` and is installed into `project/addons/godot_synth/bin/`. The Windows output name must match `project/addons/godot_synth/godot_synth.gdextension` (entry symbol `synth_library_init`). Godot must be closed while building, or the DLL is locked.
- `godot-cpp/` is a git submodule pinned to `10.0.0-stable`, and `SConstruct` passes `"api_version": "4.7"`. A clean build compiles godot-cpp first (about 7 minutes). A fresh worktree can copy the built `godot-cpp/` from the main checkout instead. Never edit anything under `godot-cpp/`.
- No binaries are committed: `bin/` folders are gitignored. `src/gen/` is generated by SConstruct and gitignored too.
- Known pitfall: `LNK4042` on `src/gen/doc_data.gen.*.obj` is treated as an error. Delete the stale `.obj` and relink.
- CI (`.github/workflows/build.yml`) builds a platform × debug/release matrix and runs `tests/offline_render.gd` in the Linux debug job.

## Architecture map

- `src/synth/register_types.cpp`: every class must be registered here (`GDREGISTER_CLASS` or `GDREGISTER_ABSTRACT_CLASS`), grouped into `register_*()` helpers. Reverb is intentionally left unregistered because of its CPU cost.
- `src/synth/core/`:
  - `AudioSynthPlayer`: the node; does voice allocation.
  - `SynthNoteContext`: per-note handle (note_on/off, `note_on_deferred`, velocity, articulation).
  - `SynthVoice`.
  - `SynthConfiguration` (abstract), plus `ConfigurationPrototype` and `SynthPreset`.
  - `AudioStreamGeneratorEngine` (abstract oscillator engine), plus `EngineFactory`.
  - `ModulatedParameter`, `ModulationSource`, `WaveHelperCache`, `PitchHelper`.
  - `SynthOfflineRenderer`: renders notes without an audio device.
  - The stream and playback classes (`SynthAudioStream`, `SynthAudioStreamPlayback`). The playback mixes on the audio thread.
- `src/synth/va/` is the virtual analog engine (the shipped one). `src/synth/chord/` is the chord engine (work in progress).
- `src/synth/mod/`: modulation sources (adsr, lfo, velocity, keyboard tracking, note duration, articulation).
- `src/synth/effects/`: the `SynthAudioEffect` base, `EffectChain`, and the `filter/`, `delay/`, `distortion/` and `spatial/` effects.
- `src/synth/time/`: `BpmManager` (runs on `_process`, so it's frame-jittered) and an empty `Sequencer` placeholder.
- `src/synth/ext/`: vendored third-party headers (`qoa.h`). Don't reformat them.
- `project/addons/godot_synth/`:
  - the editor plugin (`synth_plugin.gd`) and the custom inspectors
  - the `keyboard/` test scene
  - the `music_engine/` GDScript sketches (arpeggio, motif, rhythms; not load-bearing)
- `docs/` is the Jekyll GitHub Pages site. Anything added there is published.
- `design/` holds internal design notes that are not published.

## Conventions

- **C++:**
  - Format with the repo's `.clang-format`: LLVM base, **tabs**, indent width 4, no column limit.
  - Source files use **LF** line endings.
  - Headers use `#ifndef NAME_H` include guards, and everything goes in `namespace godot { … }`.
  - Classes use `GDCLASS(Name, Base)` with `static void _bind_methods()` in `protected:`.
  - Parameters are prefixed `p_`. Properties are `set_x`/`get_x` pairs, exposed with `ClassDB::bind_method(D_METHOD(...))` plus `ADD_PROPERTY`.
- Modulation sources implement `get_value(const Ref<SynthNoteContext>&) const`, `reset()` and `duplicate()`. Effect parameters should be `ModulatedParameter`s so they can take modulation.
- **Audio-thread code** (anything called from the playback's mix) must not allocate, lock a mutex or call into Godot objects in the per-sample or per-block path. Hand data between threads through preallocated lock-free queues.
- Update CHANGELOG.md (Keep a Changelog format) for user-visible changes.

## Godot 4 rules

- Godot 4.x APIs only: `@export`, `@onready`, `await`, `super()`, typed signals. No Godot 3 names.
- Static typing everywhere in GDScript: `var x: int`, `func f(a: float) -> void`, typed arrays (`Array[int]`).
- Never hand-edit `uid=` values or `[ext_resource]` ids in `.tscn`/`.tres` files. Keep the `.uid` files that sit next to scripts, and commit a new `.uid` file with its script.
- A `-s` script that calls `ResourceSaver.save` drops the `uid=` fields from scenes, so never resave existing scenes from a script.
- Don't add autoloads, plugins or project settings unless the task says so.
- No `await` on clock, transport or audio paths.

## Headless checks

- Parse-check one script: `"$GODOT" --headless --path project --check-only --script res://addons/godot_synth/<file>.gd`, where `$GODOT` is `/c/Godot/4.7/Godot_v4.7-stable_win64_console.exe`.
- Add `--verbose` to see which scripts load and to get details on leaked instances.
- Known noise: the editor prints about 148 `Instantiated ModulatedParameter used as default value` warnings, and `smoke.gd` reports 2 leaked ObjectDB instances at exit. Neither is a failure.
